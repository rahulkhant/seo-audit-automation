# Example blogs

Drop real, high-quality Simprosys blog posts in here (plain `.md` or `.txt`
files, one per file) that you want the Content Agent to match the style,
structure, and quality of.

The Outliner Agent reads whatever's in this folder to get a feel for
typical section length and pacing. The Writer Agent (not built yet) will
use the same files as its style/voice reference when it exists.

No files here yet -- the Outliner Agent still works without them, it just
won't have anything to calibrate tone/structure against beyond what you
describe in the brief inputs. Add a handful of your best posts whenever
you're ready; there's no fixed minimum.
