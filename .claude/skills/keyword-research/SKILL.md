---
description: "Keyword Research module: import a batch of competitor keyword sheets (Google Sheets links), deduplicate within the batch, save it, rebuild the dashboard's Keyword Research page (master list + batch history), and push."
---

You are running the Keyword Research Agent. Rahul (or a teammate) pulls
competitor keyword exports from Google Keyword Planner (or similar) into
one Google Sheet per competitor, then hands you the list of sheet links.
Your job: read every sheet, deduplicate keywords within this batch,
compute the insights, save it, and rebuild the dashboard -- no separate
manual step for each piece.

Do the following, in order:

## 1. Confirm working directory
If not already there, change to `/Users/rahul/Desktop/Automation/seo-audit-automation`.

## 2. Collect the inputs
If the user's request already included some of these, don't re-ask:

- **The list of Google Sheets** -- one link per competitor, plus that
  competitor's name (e.g. "Competitor A: <link>").
- **A label for this batch**, optional (e.g. "Q3 2026 competitor scan").
  If none given, it'll just show as "Batch #N" on the dashboard.
- **Whether this batch should be added to the master keyword list**, or
  kept as a standalone report. Ask plainly if it's not already clear --
  this is a real decision each time (see
  `keyword_research/database.py`'s module docstring for why), not
  something to default silently.

## 3. Read every sheet
For each Google Sheet link, get its data as rows of
Keyword / Avg. Monthly Search Volume / Difficulty / YoY change (column
names in the actual sheets may vary slightly in wording/capitalization --
match them by meaning, not exact text).

Try, in this order:
1. If a Google Drive/Sheets tool is available in this session, use it to
   read the sheet directly from the link (extract the file ID from the
   URL if needed). This only works if the sheet is actually reachable
   from whatever Google account is connected.
2. If that isn't available or a specific sheet can't be reached that way,
   ask Rahul to export that sheet (File > Download > CSV or Excel) into a
   folder you specify, then read it directly from disk.

Don't silently skip a sheet that fails to load -- tell Rahul which one
and why, and confirm whether to proceed without it or fix access first.

## 4. Assemble the batch
Build one JSON object:
```
{
  "label": "...",                 // or null
  "include_in_master": true,      // or false, per step 2
  "sheets": [
    {
      "competitor": "Competitor A",
      "rows": [
        {"keyword": "...", "avg_monthly_search_volume": 1200, "difficulty": 34, "yoy_change": 12.5},
        ...
      ]
    },
    ...
  ]
}
```
Every row needs a `keyword`. Missing numeric values are fine as `null` --
don't invent a number. Write this to a temp file.

## 5. Save the batch
```
.venv/bin/python3 -m keyword_research.save_batch <path-to-batch.json>
```
This flattens every sheet's rows, deduplicates keywords within the batch
(case/whitespace-insensitive; the first sheet a keyword appears in wins
on its numeric values, but every competitor whose sheet contains it gets
recorded -- see `keyword_research/database.py`'s `dedupe_keyword_appearances`),
and prints the new `batch_id`.

## 6. Rebuild the dashboard -- all six pages
```
.venv/bin/python3 -m agent4_dashboard.build_dashboard_metronic
.venv/bin/python3 -m agent4_dashboard.build_reporting_hub
.venv/bin/python3 -m content_agent.build_content_page
.venv/bin/python3 -m activity_agent.build_activity_page
.venv/bin/python3 -m keyword_research.build_keyword_research_page
```
(All five build scripts, not just the Keyword Research one -- the shared
sidebar is regenerated by every page's own build script, so all of them
need to run to stay in sync, same reason every other skill in this
project rebuilds more than just its own page.)

## 7. Commit and push -- automatically, no separate confirmation step
Same established pattern as the Content Agent and Activity Agent skills.
```
git add data/seo_audit_history.db docs/keyword-research.html docs/keyword_research_exports/ docs/index.html docs/history.html docs/reporting.html docs/content.html docs/activity.html docs/reports/reporting-hub-latest.pdf
git commit -m "Add keyword research batch: <label or batch_id>"
git push
```

## 8. Report back
Tell Rahul:
- The batch_id, sheet/competitor count, and unique keyword count (vs. the
  raw row count before dedup, so the scale of the cleanup is visible).
- Whether it was added to the master list or kept standalone.
- A one-line highlight from each insight: the top opportunity keyword (if
  any), the biggest rising/declining keyword, and the most contested
  keyword.
- The dashboard link: https://rahulkhant.github.io/seo-audit-automation/keyword-research.html
- The direct download links for this batch's Excel sheet and PDF report.
